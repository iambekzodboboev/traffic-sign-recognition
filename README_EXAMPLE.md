# M8C2 Demo Capstone

This is a small classroom demo repository for Module 8, Class 2.

The project is intentionally simple so students can see the workflow clearly:

- organize a capstone repository;
- make a small manual change;
- review the Git diff;
- commit locally;
- push and verify on GitHub;
- then repeat the same controlled workflow with an AI coding agent.
