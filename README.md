# Traffic Sign Recognition

A machine learning project to recognize traffic signs from images.

## Project Goal

Build a model that classifies traffic signs, then explore ways to serve it
(e.g. a Telegram bot or a small web app).

## Status

See [PROJECT_STATUS.md](PROJECT_STATUS.md) for the current stage and next steps.

## Plan

1. Repository and project setup (this step)
2. Add dataset
3. Data audit / exploration
4. Baseline model and experiments
5. Model selection
6. Serving the model (Telegram bot or web app) - decided later
