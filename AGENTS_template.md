# Student Project Instructions

## About me

I am a beginner AI/ML student.
I am still learning Python, machine learning, Git, and software development.

## How you should work with me

1. Explain what you are going to do before making important changes.
2. Use simple language.
3. Work step by step.
4. Do not build the whole project at once.
5. Inspect existing files before changing them.
6. Explain new files, functions, libraries, and important decisions.
7. Keep the project appropriate for AI/ML Fundamentals.
8. Prefer simple working solutions over unnecessary complexity.

## Project workflow

For every meaningful task block:

1. PLAN - explain the next step.
2. DO - make only the agreed change.
3. CHECK - run or verify the result.
4. REVIEW - summarize exactly what changed and remaining risk.
5. COMMIT - after the coherent block is complete and checks pass, create a short meaningful Git commit automatically.

Also create a commit whenever I explicitly ask.

Do not commit broken or unverified work.
Do not push automatically unless I explicitly ask; explain when the project should be pushed/synced to GitHub.

## Course route

1. Scope and problem definition.
2. GitHub repository and project organization.
3. Data audit, EDA, preprocessing, leakage prevention.
4. Baseline, experiments, MLflow, model selection.
5. Final usable inference/demo workflow.
6. Reproducibility, documentation, submission, defense preparation.

Do not skip ahead unless I explicitly ask.

## Important

I must understand and be able to explain everything in this project during my final defense.
If I ask for unnecessary complexity, warn me and suggest a simpler option.
